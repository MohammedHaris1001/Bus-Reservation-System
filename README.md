#Bus Reservation System in C

##Project Description

The **Bus Reservation System** is a console-based application developed using the C programming language. It allows users to book bus tickets, cancel reservations, search for bus routes, and check seat availability.

The project uses a **Singly Linked List (SLL)** to manage passenger reservation records, structures to store bus and passenger details, dynamic memory allocation for passenger records, and file handling to save reservation data.

##Features

1. **Admin Login**
   - Secure admin login using username and password.
   - Access passenger reservation details.
   - View seat allocation.
   - Search available bus routes.
   - Save passenger records.

2. **User Login**
   - User authentication.
   - View predefined available buses after successful login.

3. **Book Ticket**
   - Book tickets by entering passenger details.
   - Automatically generate unique ticket numbers.
   - Allocate available seats.
   - Store passenger and journey details.

4. **Cancel Ticket**
   - Cancel an existing reservation using the ticket number.
   - Remove the cancelled passenger record from the linked list.

5. **Seat Allocation**
   - Display seat availability for each bus.
   - Identify booked and available seats.
   - Prevent duplicate seat allocation on the same bus.

6. **Search Route**
   - Search for buses using source and destination.
   - Display matching bus details.

7. **Display Passenger Details**
   - View passenger reservation information.

8. **Save Records**
   - Store passenger reservation records in a file using file handling.

9. **Exit Application**
   - Exit the system safely.

##Technologies Used

- **Programming Language:** C
- **Data Structure:** Singly Linked List
- **Memory Management:** Dynamic Memory Allocation (`malloc`, `free`)
- **File Handling:** File operations (`fopen`, `fprintf`, etc.)
- **Concepts:** Structures, Pointers, Functions, Loops, Conditional Statements, and Modular Programming.
